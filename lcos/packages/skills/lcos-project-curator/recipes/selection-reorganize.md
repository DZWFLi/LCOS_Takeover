# Recipe: Selection Reorganize

```text
读当前 Selection + Presentation
→ 标记 manual pins / protected items
→ 理解内容：主题、层级、主辅、关系重点
→ 形成最小 ChangeSet / ReorganizeProposal
→ 在当前 Surface 展示候选变化
→ 用户 Keep / Revert（PASS8 fallback: ghost → accept → apply / rollback）
→ verify
```

默认只改 Presentation。Agent 不手算坐标；几何层负责节点真实尺寸、间距、对齐和连线跟随。
