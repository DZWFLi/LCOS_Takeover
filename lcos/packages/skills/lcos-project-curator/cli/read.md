# CLI: read

```bash
lcos project show <id>
lcos run context <run-id>
lcos conversation show <project-id> <conversation-id>
lcos conversation messages <project-id> <conversation-id> [--pinned]
lcos resource read <project-id> <resource-id> [--path name] [--limit N]
```
