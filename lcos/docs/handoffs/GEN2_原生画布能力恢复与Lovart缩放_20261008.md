# 原生画布能力恢复、Lovart 缩放与点击空白退出

本轮把现成画布能力接回可见入口，保留原 API/session/geometry；不重新做后端。已完成本批入口与手势修正，未宣称全部 Gen2 前端收口。

## 用户能直接使用的变化

- Main / Context / Workflow 都有「画布助手」和「设置」按钮。
- 原生 ChatPanel、Agent/模型选择、历史、PreviewWorkspace tabs 与节点大视图继续复用 Huabu；原面板请求由 LCOS 已有专业窗口接住，默认停靠右侧。
- 点击画布空白收回当前前景专业窗口或输入框，未发送草稿保留。Esc 与点击共用退出顺序，叉号保留作备用。
- 画布平移、右键、拖放进行中不收回接收面；从前景控件拖到背景，也不当成点击退出。
- 单节点使用 Lovart demo 的细框、小白色角点、透明的大命中区；文字使用左右宽度拖柄。尺寸、最小尺寸、比例、吸附和 undo 仍由 Huabu/React Flow 执行。
- 修正设置 Esc 被底层专业窗口先消费的问题。
- Core-bound 材料的原生大视图只读，避免旧编辑器只改 node.data 而没有保存 canonical 正文；现有 canonical 正文编辑入口保留。
