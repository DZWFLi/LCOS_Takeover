当前 resolveNativeMaterialSources.ts:148 发送 nativeCarrier；当前 Core routes/imports.ts:152 与 import-copy-service.ts:71 承接永久绑定，旧 OS Core 没有此实现。接旧 Core 可能出现“文件导入成功，但原生节点身份没永久绑定”的误验。

实际选址源码：

- huabu/apps/web/vite.config.ts：shell 环境优先于 apps/web/.env 和 Huabu 根 .env；API 默认 3001、Core 同源代理默认 43121，均可显式配置。只检查固定白名单的非敏感路由键，未打印 .env 或凭据。
- apps/local-core/src/index.ts:92：默认打开当前工程 .data/phase2.sqlite，种开发项目，启动观察器和 Run 自动同步；启动并非只读。
- huabu/apps/server/src/data-dir.ts：默认 cwd/data，可由 HUABU_DATA_DIR 显式指定。
- huabu/apps/server/src/modules/workspace.ts:122：HUABU_WORKSPACE 在开机时锁定并准备磁盘 workspace。
- huabu/apps/server/src/server.ts：初始化 storage/secret store；有凭据的 OAuth provider 会预热。secret store 还有环境变量 fallback。
