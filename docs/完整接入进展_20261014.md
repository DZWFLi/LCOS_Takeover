## 产品定位与接入优先级：Agent 是画布里的工作主体

用户进一步明确：目标是保留 TapNow 成熟的画布与图文交互，让 LCOS 已有的画布 Agent、上下文、工作流成为这张画布的增量能力。不是重新实现一套 Canvas；也不是仅用厂商聊天面板换成本地 API 就结束。

产品形态可以理解为给这套成熟交互增加一次「LCOS 功能更新」：Agent 是能接收材料、发起任务、呈现状态和回收产出的画布工作主体，不是聊天侧栏或普通文字卡片。沿用的是厂商已打磨的交互机制；LCOS 决定任务、上下文、工作流和产物的业务含义。这里仅依据已拆的本地版本作接入判断，不断言厂商最新产品没有相关功能。

实现上分两种接法：已有等价动作由窄适配层翻译到 Core/Huabu；厂商没有对应概念的能力，用现有节点类型扩展、窗口与菜单入口承载 LCOS 的成熟组件。后者是新增薄入口，不把 Workflow 假装成生成接口，也不把三现场切换、Saved Context 或节点堆叠混成同一个业务对象。画布连线不能直接当可执行工作流，ColorPin 也只有在导航语义对得上时才映射为地图钉。
