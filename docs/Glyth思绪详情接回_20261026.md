# Glyth 思绪详情接回

结论：节点现有状态主按钮继续直达回答 / 审阅 / 恢复；同一状态行补一个紧凑详情入口，点击打开 TapNow 原 Popover。详情支持公开长句、待切换的新进展、最近两条历史、查看过程与 Escape 回焦。节点没有增大，没有挂旧浮动窗口。

本支产品源码已稳定。根代理负责原 nodeTypes 注入与准确右栏路由，真实项目页面验证另列；本文的动态 / 历史 / 长文证据均来自明确受控的真实原组件夹具，不通过发送模型造状态。

短高复验补充：真实原页在 400px 高度发现“内容仍在 viewport 内，却被原通知 / Dock 盖住”。本轮已改为读取原顶栏、Dock、底部控件、Sonner toast 的实际 DOM rectangles，只把原 `pr` 的 `collisionPadding` 传准；仍由原 Popover flip / shift。详情的高度 / 宽度消费原 Radix available-size 变量，在同一个内容体内滚动。没有升 z-index、隐藏通知或新建碰撞系统。

## 具体接回

- [native-glyth-thought-detail.tsx](../lab/pilot/native-glyth-thought-detail.tsx) 新增持续挂载的节点 leaf。原 `resolveGlythThought` 是唯一思绪来源；这里只接公开摘要与 detail，不取 raw reasoning、系统说明或完整 assistant 回复作“思考”。
- 纯展示模型沿旧 ThoughtView 的规则抽取：scope / identity 改变清空；正文距离上次展示最少 1300ms 后替换；hover / focus / 已展开时冻结 pending；最多保留 4 条观察过的公开记录，详情显示最多 2 条较早记录。点击“有新进展，点击查看”可明确切换到 pending。
- Popover 内容正常卸载，短暂模型仍在节点 leaf 中，关闭重开不丢 pending / 历史。不保留隐藏 DOM，不跨 Portal 搬 DOM，不新增领域 store。
- 原 `pr/IQe` 继续负责唯一 Popover、碰撞、outside 与 Escape；原 `gm` Button 继续负责真实按钮。有限 props 不转 data / aria / ref，leaf 窄范围给其唯一真实 BUTTON 补语义及焦点引用。
- `onOpenProcess(thought?)` 只交付**当前实际显示**的公开 thought；无摘要时文案“查看对话”，传 `undefined`。不偷偷改成最新 pending，不创建会话 / Run，不恢复或发送。根代理复核当前身份，再沿原右栏准确 Run / timeline item 定位。
- `suppressed` 只用于实际隐藏、拖动或身份 / 现场无效；恢复、待回答、`canSend=false` 不抹掉阅读。document.hidden 关闭内容并停止显示 timer；卸载释放 timer、visibility listener 与焦点 RAF。reduced / forced colors 保持文字和按钮可用。

接口：

```ts
NativeGlythThoughtDetail({
  thought?: GlythThought,
  identity: { projectId, conversationId, canvasId, nodeId },
  NativePopover,
  NativeButton,
  onOpenProcess: (thought?: GlythThought) => void,
  suppressed?: boolean,
})
```

[CSS](../lab/pilot/native-glyth-thought-detail.css) 将详情入口放在原状态行内，主按钮 / plain summary `min-width:0`，disclosure 不压缩；详情桌面宽 280px、按原 Radix 实际可用宽 / 高收缩，去掉原先 440px 固定高度上限。原 121×142 节点占位与画布几何不变。触发按钮桌面 24px，原状态的两行文字保留；粗指针 32px，内容动作最少 44px。

避让订阅只在原 Popover 打开时存在：原 chrome ResizeObserver、相关 DOM mutation、resize / scroll / 有限 entry transition。最后一条 toast 移除也匹配其空 toaster owner，不能留下陈旧 padding；toaster 本身的零高盒不作为障碍。关闭、hidden 或卸载释放这些观察口。

## 原 ThoughtView 的取舍

| 原能力 | 本批结果 |
|---|---|
| 公开摘要、96 字截断的完整 detail | 取用原 resolver，详情读取完整公开句子 |
| 1300ms 替换 / engaged pending | 已接到持续节点内的详情展示模型；明确点击可切新进展 |
| 4 条短暂记录 / 详情最多 2 条 | 已接；不是持久化 timeline，刷新不承诺保留 |
| 点击展开 / Escape / 回真实按钮 | 已接原 Popover；不靠全局 Escape 拦截 |
| 查看过程 | leaf 传精确当前 thought；原右栏路由由根代理接线并实屏验证 |
| M2 身体光波 | 保留上一批原 renderer 接入；hover 只是 quiet GUI，不伪装业务 thinking |
| 6200ms、done 4400ms 自动播报后收起 | **本轮暂不接**。当前原页先保持续摘要 + 用户主动展开；自动浮出／收起仍按场景评估，不能把自动动效等同于抢焦点，也不宣称旧自动 ThoughtView 全恢复 |
| 旧 hover 展开与 160ms 浮窗过桥 | 原点击 Popover替代；hover 不打开详情、不抢 Composer 焦点 |
| 旧 `CanvasFloatingPopover` / 旧 `openWindow` | 不取用；原 Popover + 原右栏承接 |
