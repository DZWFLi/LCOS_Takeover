## 授权与本轮边界

用户已选择 Rare UI Folder 原示例。此次只让原生 Core Collection 的收起卡面采用它的文件夹造型、真实材料预览与开合动效；TapNow 继续拥有原 Gallery、主画布 Group、拖动、相机和历史，Core 继续拥有同一个 Collection／名称／成员／绑定。

- Goal：合成 Collection → Rare UI 文件夹预览开合 → 原 Gallery → Core 命名／成员增删 → 原主画布展开／收起 → 拖动、原撤销重做与刷新。
- Files：`lab/pilot/native-pile-ui.tsx` 的薄卡面挂载、独立 Folder leaf／局部 CSS、必要的精确原件接缝、定向与现有 GUI 回归脚本。只读复用现成 RareFolderComponent，不搬 Atlas／GN2 Collection body。
- Before → After：原 Pile 可视卡面 → Rare UI Folder 可视卡面；既有唯一 ReactFlow／Core identity／Gallery／Group／O8 保存链不变。文件夹开口是局部呈现，不冒充主画布空间展开。
- Interface：不新增 Core API、领域类型、数据库、历史栈或 Schema；不改 Run／Bridge／Provider。不新增 hash、冻结 contract、baseline 或 gate。
- Tests：直接复用原 Folder 与真实内容插槽；开口／hover 零持久写、零历史；精确原 Gallery 成员；既有 Collection 全流程与文件完整字节对照；查看实际截图及错误日志。
- Risk：原 Pile 把成员以 ReactFlow 虚拟扇片呈现，不能简单叠一个文件夹遮住旧卡。需窄接可视投影，保留普通 Pile 原路径，保留 Gallery 原 owner。三张预览不代替完整 Core 成员。
- Rollback：只撤本轮 leaf／视觉接缝，不迁移数据。所有 GUI 写入仅在新建的 `isolated-*` 合成 runtime；不操作原 17881 或已交付 53861，不重建用户已使用的 fixture。
