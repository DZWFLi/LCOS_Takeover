## 解决的真实缺口

- 原预览服务只认最初三个画布。现改按真实、唯一的 Core Workspace 归属接纳已打开的方法子现场；三视图根地址保持不变。
- 原一般投影将跨 Scope 材料当作当前 Artifact 主视图，实际报主视图不唯一。改走已经存在的确版跨现场放置服务，保留原材料和版本。
- 原方法弹层在阅读前后切换 modal 状态时会重建内容。返回改为恢复当前原页面节点，不能继续抓已经失效的旧 DOM。
- 来源页恢复时，外层菜单曾在详情挂载前收到失焦关闭，导致详情短暂出现后消失。生命周期记录确认后，用已有“正在恢复来源页”状态保护交接；正常关闭仍有效。
- 小屏样式此前依赖子元素序号；新增编辑入口后绑错层级。现给原布局的真实区域标识，修正媒体区、文字区和宽度，360px 不再裁正文。
- 任务同步曾拿子现场 Canvas 与三视图根 Canvas 比较，误报“现场不一致”。现使用 Host 从 Core 读回的确切 Workspace／Surface 映射，仍核对项目、现场、画布和 API 身份；没有删掉同步或隐藏错误。
- 原材料取用后只收起详情，外层菜单仍在退场。现沿原取用关闭回调一起收起，再恢复原输入。
- 旧结构占位与真实材料身份分开处理：纯结构标记不伪装成材料；真实材料即使承担结构标记仍可阅读、引用。没有固定版本的 View 按原语义读 Current，明确固定但缺失的版本仍拒绝替换。
