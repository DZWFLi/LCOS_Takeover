# Gen2 局部接入实验计划

目标：继续拆 TapNow 到可以开始 Gen2 局部采用的程度，展示后停止扩大范围。

当前未覆盖：24 个独立工具只有 3 个真实操作过、21 个未逐项验证；已操作的仍加载原 HTML。Canvas/Library 只证明合成节点显示/拖动、目录/素材元数据列表与自定义面板，没有真实内容、保存、生成或 Core 接通。

## 范围修订：图片、文本节点与画布管理

用户明确认为调色价值不大，本轮已取消该方向的实现。下方原调色设计仅保留为历史计划，不是完成项；`--adoption` 草稿缺 workbench，不能作为交付入口。

实际执行改为：原图片上传/替换、文本富文本编辑、节点增删复制、历史恢复、多选/框选、坐标与文本尺寸、连线、搜索、缩放/平移、画布创建/切换/改名、隔离保存及刷新恢复。新入口 `--takeover --cut --nodes --port 17877`。

Gen2 只读数据源与原客户端方法的模拟测试继续保留；没有真实 Core 或 Huabu 写入。当前完整实测见 [节点与画布功能实测](./节点与画布功能实测_20261013.md)。

原计划：回收原 Color Adjust 的 vanilla UI、18 参数与像素算法，拆开 DOM 生命周期、输入预览、控件状态、Apply 回调；做独立入口与原 Canvas 调用示例。另把 Gen2 现有项目/Artifact/Revision/内容读取方法接成可注入的数据源。

文件：lab/components/recovered/、lab/adapters/gen2-feature-source.mjs、lab/adoption/、lab/gen2-client-build.mjs、lab/server.mjs 的新 --adoption profile、相应 scripts 测试/测量及 docs/evidence。原 reference/ 与 lcos/ 不改。

Before/After：原来只能加载整 HTML、用 TapNow SDK 请求动作；拆出后可独立 mount/update/destroy，输入四种身份与 Blob 预览，状态和 Apply 经我们传入的回调。不是恢复原作者 TSX，也不是 Gen2 正式页面已采用。

既有接口：复用 CoreProjectClient.listProjects 与 CoreArtifactClient.listArtifacts/listArtifactRevisions/getFileRecordContent，不造第二 HttpClient、canvas 或领域真值。用 Node 自带 TypeScript 转译把四份原 client 编译到新 .runtime，在明确 fixture HTTP 响应下执行原方法；不启动真实 Core、不继承 token/DB。

测试：原算法的纯函数、默认像素不变/曝光变化/alpha、实例参数与销毁；项目归属、currentRevisionId 精确选择、旧版本明确选择、内容缺失/错误 MIME/大小/无客户端/Apply 拒绝；原 Gen2 client GET 路径/envelope 与浏览器实际选择、滑杆、原图比较、重置、刷新状态、动作拒绝、移动视口/控制台及截图。

风险：这是独立 donor 研究展示，不替换 Gen2 的 Huabu Spatial Truth，不进行 canonical writes。Apply 未提供合法写 owner 就明确拒绝；fixture 不能冒充真实连接。CSS 隔离、单实例局部状态、事件/RAF 清理，保留当前宿主的 origin/path/CSP/网络约束。

回退：不用 --adoption 即保留原实验行为；新 runtime 与模块隔离，不改旧状态，不停止未知服务。没有新增 hash、冻结 contract、baseline 或 gate。

停点：一块回收的原工具 UI/算法独立可编辑；真实 Gen2 client 方法在明确模拟边界下接受同一份身份/内容；宿主可演示、单元与真实操作证据齐全。达到后只交用户查看，不自动扩到其余 21 工具或真实项目写入。
