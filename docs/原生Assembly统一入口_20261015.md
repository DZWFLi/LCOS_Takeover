# 原生 Assembly 统一入口

## 本轮目标与接法

继续沿 TapNow 原组件施工：先把原 Library 列表／瀑布流／详情接到 Core Warehouse 的真实读模型，提供准确版本预览和本次引用入口；再沿原空间导航补定位。不是把材料库换个名，或把 GN2 AssemblyBody／Rail 整页搬来。Drop 单独一轮，不扩做真实 Provider 执行。

- Files：`lab/` 新的 opt-in Library／Assembly 薄适配、launcher／server 参数、目标测试及本文；原安装包、`reference/`、`lcos/` 与原 GN2 只读。
- Before → After：现 Library 只按 Artifact Current 形成目录；新模式从已有 Warehouse 读物种／来源／使用情况，以同一 Artifact／View／Revision／FileRecord 显示与引用。原列表、搜索和预览保留。
- Owner：Core 仍拥有材料／版本／成员；原 Composer 拥有本次消息引用；原 TapNow 拥有浏览、选择与相机。不给 Library 新建第二资产表或成员账本。
- Tests：目标纯函数／临时真实 Core 集成后，独立合成 runtime 实际测试打开、搜索、准确版本、选取／取消／引用和定位；浏览不得触发材料、成员、Run 或 Provider 写入。
- Risk：原 asset 的 ID／类型不能冒充 SourceRef；历史 View 不能偷换 Current；迟到读回不能污染新输入。未知动作保持明确未接，不假报成功。
- Rollback：禁用新 opt-in flag，保留全部隔离数据与证据；不迁移旧项目。

本次开始时 17881／53861／56111／56225 均无监听；不替用户重启或迁移旧 runtime。另建新 runtime 与预览，原运行数据不打开、不修改。

可看版：[56234 · 原生 Assembly](http://127.0.0.1:56234/canvas/surface-core-workflow)。这是独立合成项目，不是原 GN2 或用户项目。

直接沿用 TapNow 原 Library 的入口、搜索框、列表、虚拟滚动、菜单和详情预览；只增加薄的准确版本／引用／定位控制。没有搬入 GN2 AssemblyBody／Rail，没有新增画布、材料表、成员账本或历史栈。原顶栏“素材库”暂保留，内部接到同一 Assembly 来源；不是只换标题。

已实测：原会话 Glyph → 原 WorkView → 原 Composer → 原 Library 搜索 → 文本当前／历史版本预览 → 历史版本加入这条未发送消息 → 取消重开不重复引用 → 原相机定位 → 图片预览 → 刷新后按同一 Core 版本读回。当前画布没有历史版本时明确提示，不跳去 Current，也不创建节点。
