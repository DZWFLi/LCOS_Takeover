# 任务更新反馈的内部披露修正 · 2026-10-26

结论：已修呈现层。原顶栏在失败时直接显示 `syncState.message`，会把网络异常或内部同步术语带给用户；现在可见反馈、hidden live 内容及重试按钮的可访问名称统一使用任务更新文案。错误、已有内容和原重试保留，没有改成假成功。

## 最小改动

源文件：[native-execution-sync.tsx](<E:/Codex 项目/LCOS夺舍计划_20261013/lab/pilot/native-execution-sync.tsx>)。

新增纯函数 `nativeExecutionSyncPresentation(state)`，只按现有 status 生成说明：

| 状态 | 用户文案 | 原可见性／重试 |
| --- | --- | --- |
| ready | 画布中的任务已更新。 | 不显示失败反馈；不新增重试。 |
| syncing | 正在更新画布中的任务… | 不显示失败反馈；不新增重试。 |
| blocked | 画布中的任务暂时无法更新，已有内容保留。 | 保留原 alert 与重试，按钮文字和 aria-label 均为“重试更新”。 |
| unavailable | 画布中的任务暂时无法更新，已有内容保留。 | 保留原 alert；不擅自新增原本没有的重试。 |

原控制器的 status／message、项目／画布／工作区／API 身份检查、迟到结果保护、watcher 释放、失败不自动重放、显式重试与 pending-save 恢复规则均未修改。原 `onClick={() => controllerRef.current?.retry()}` 闭包不变。内部异常仍保留在控制器状态，未清掉故障记录。
