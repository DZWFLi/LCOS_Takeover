## 保护与并发

- 复用唯一 Workspace/Scope/项目、准确 node/ref/binding；进入子现场无需匹配根三视图快捷 Canvas。
- 写前重读 canonical DTO 和事实，锁、拖动、换现场、换真实对象会拒绝；正常同 Artifact/View 版本前进仍可修改 GUI。DTO await 后重新取原 graph，避免拿旧 graph 误拒正常新版本。
- 原节点锁从 raw node 经主代理补齐的最终 DTO 映射保留到 typed carrier；不因 Run 投影漏字段而越过锁。
- HTTP 写结果丢失仅返回 unknown/pending；不自动再次创建。主代理在原 Core 同步 create 段补准确 target/scope/source 去重，覆盖用户与 Agent 同时提交，不另加进程 Map 或第二库。
- 并发另一方已移除准确原记录时，DELETE 404 必须实读该精确记录确实不存在，才报告本次无新增修改；原 404 仍在 coreResponse，没有伪造成功回执。
- Core 原 ChangeSet 事件 `mutation/change_set.changed` 是现成失效信号。初审发现导航 Host/已开目录缺同现场事件刷新；主代理本批已接原共享 `watchProjectChanges` 与保留相机返回的 refresh owner，实际最终效果由其组合测试/真页验收。
