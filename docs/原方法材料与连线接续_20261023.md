## 解决的实际问题

1. **整份方法材料与步骤材料此前含义不清。** 现在明确显示“关联材料”列表，列表中的材料随整份方法取用；步骤勾选只说明这个步骤使用哪些。取消一个步骤的勾选，不会暗中改变其他步骤或整份方法。
2. **移除材料会留下引用。** 从关联材料列表移除时，同步解除本方法中的步骤和分支引用，清理对应的位置、层级、排列、连接、标记及空间组件绑定。剩余成员、结构文字和几何不受影响；材料原件、其他方法和 Workspace 不删除。空的局部组织分组随最后一个成员解除，不影响其他组织分组。
3. **独立分支能保存却不能导入。** 原 Presentation 允许独立结构标记，但原 ZIP 导入要求结构身份必须是一份材料。修正这一不一致，同时保留结构格式、分支身份、目标归属等验证。原 ZIP 导出／导入实际往返通过。
4. **材料可能在取用时漏掉。** 方法材料即使也承担结构标记，或只作为分支目标，仍构造准确引用。生成的阅读正文不再使用内部结构种类和原始身份作为显示文案；用户自己写的原文不删改。
5. **删除最后一条连接后编辑区意外收起。** 最终实屏复验发现并修正；现在展开状态由用户控制，数量归零仍可直接继续添加。分支区同样处理。
6. **归档材料的边界。** 已归档材料的历史引用仍保留、可继续编辑方法；新增材料列表不把归档材料重新带入。真实 Core 事务测试覆盖了两条路径。

条件与分支目前是创作说明，随方法交给助手理解，**不是自动执行条件的引擎**。这是原有数据模型的实际能力，未用按钮外观冒充自动运行。
