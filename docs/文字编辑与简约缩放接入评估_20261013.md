# 文字编辑与简约缩放接入评估

## 结论

用户已明确指 Gen1 完整文本节点，两大视图是“文本块”和“大纲导图”。据原 Gen1 源码修正：双视图展示与编辑接入为中等难度；完整行为、分支摘取、保存反馈与重开恢复对齐为中等偏上。上一轮“偏低到中等”只适用于基础格式编辑，不覆盖整套 Gen1 功能。

功能内核已有可读源码，GN2 也承接了部分成熟组件，所以无需重造编辑器或导图算法。若仍要求原厂 Tiptap 整包不动、往其内部再注入 Gen1 状态，难度更高，且不是当前 leaf 接入路线。

这里判断的是当前独立实验的集成成本，不是承诺全功能已经接好，也不以源码存在代替真实浏览器验证。本轮只读核对，没有修改实现或操作用户数据。

用户纠正后已定位成熟原 Gen1 源码：`E:/TRAE项目/LCOS0.1收口/review/LCOS_Gen1_Drop_Rail整套对照_20261009/runtime/Gen1_3e99769`。原编辑器是 InlineNoteEditor / MindMapEditor；上一轮找到的 Gen1TextDocument 仅是阅读代理，不作为完整编辑功能依据。

## 完整接入的具体难点

1. **不丢结构/格式。** 实际执行原 parseOutline → serializeOutline：`# 一级标题\n**重点** ==高光==\n  - 子项 #标签` 会变成 `- 一级标题\n  - 重点 高光\n    - 子项 #标签`。层级与标签保留，但标题/粗体/高光标记发生变化。显示导图不应覆盖原正文；编辑后写回需要明确保真范围，不能把“共用文本”说成字节无损往返。
2. **接宿主，不只挂组件。** 原 InlineNoteEditor 通过特定 DOM 标记逐帧测量节点、portal 到 body，并读取 shell 安全区。当前 Huabu body seam 需要自己的节点几何/编辑浮层适配，不能原样套旧 App。
3. **摘枝是真创建材料。** Gen1 预览分支拖出先派发事件，再由 ProjectCanvas 换算世界坐标、App 调 Core 创建 Artifact/View。仅显示 SVG 不会带来这条业务链；应接当前 GN2 已有 createProjectText，而非复制旧全局 App 状态。
4. **视图状态须真实恢复。** 原 Gen1 noteLayout/noteOutline 是会话 Map，预览折叠也是局部 Set；这不证明跨刷新持久。GN2 已有 Huabu 呈现偏好字段可承接，但要实测切换、折叠、保存与重开，不能照搬旧缓存当持久化。
5. **完整输入与保存。** 文本选区、导图快捷键、普通画布拖动及 resize 不能抢事件；正文保存、标题更新、未知回执和草稿保留需要沿现有成熟保存链，不退回 demo 的两按钮状态。

## 修正后的推荐组合

以 Gen1 文本/导图功能内核和已采用的 GN2 实现为能力来源，TapNow 提供节点外观与正文排版，GN2/Huabu 提供简约 resize、空间与相机，Core 管正文、身份与版本。不是给 TapNow 多补几个按钮，也不是同时运行两套画布或两份正文。

## 缩放要分三层

| 需求 | 现有基础 | 难度判断 |
| --- | --- | --- |
| 细框、小把手、左右拉宽文字框 | 原 LcosNodeResizeHandle / NodeWrapper | 偏低，核对文字载体类型与高度规则 |
| 画布滚轮/触控缩放的感觉 | 原 Canvas 指针与 React Flow viewport | 基础已在；保留原手势，再验证交互 |
| 拖动时字号和整段内容一起放大 | useTextAutoSize 有字号锁定与测量，但适用原文本模型 | 中等，需对齐 Markdown 标题层级、换行、内容高度和编辑器坐标 |

当前实验文本是 note 载体。GN2 的两侧宽度手势特判 text，不能仅复制 CSS 就宣称行为已齐平，也不应为了视觉动作更换 Artifact 身份。

## 推荐怎么接

保留 TapNow 节点外观和正文结构，接现有编辑内核、格式工具条与简约尺寸控件；Core 保存链和 Huabu 空间链继续沿原职责。不要同时挂两套 editor store 或 camera。

最小第一步：为现有 MilkdownEditor 接 onReady / instance 和现有 FloatingToolbar，让基本文字格式可实际点击；沿原 NodeWrapper 确定文字宽度手势，再测输入、拖动、保存和刷新。

完整功能第二步：草稿保护、未知保存回执核对、重试、跨 scene 保护、版本冲突、撤销等要接原成熟逻辑。LcosCanvasTextBody 带 session / descriptor / reference store 等依赖，不适合整段机械复制进简化 pilot。

实际难点是选字时不拖动画布、缩放时选区/浮动工具条位置正确、改宽度后高度不反复抖动，以及编辑格式能保存并在呈现态正确读回。色彩、链接、表格、内嵌图片等需要逐项核对；当前呈现适配会去掉 HTML/内嵌图片并把链接变普通文字，不能据此声称完整富文本无损。
