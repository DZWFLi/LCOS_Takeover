## 实际原因

原 jF 的 `[data-library-panel]` 是 `fixed left-4 top-16 z-[60]`，但它由 H7 直接渲染在 eG 的 `[data-canvas-container] [contain:paint]` 下，原本没有 Portal。Canvas 缩成 305px 时，这个 containing block 同时限制其 fixed 几何与绘制：实屏记录 panel 高181px、列表仅17px。Dock 则已 Portal 到 body、全局 z40。

所以只降 Dock 或把库的局部 z60 再调高都不够：裁切和 fixed 定位归属仍错。没有改 Canvas containment、相机或所有 overlay 的 z。
