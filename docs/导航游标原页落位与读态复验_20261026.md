| 问题 | 修改 | 边界 |
|---|---|---|
| 图像约 98% 仍在视口里，仅右侧锚点放不下，就提前变成箭头并压到图内 | 以目标与实际可用画布是否有正面积交集判断可见性。可见时依次找目标外侧安全位置；真正离屏才变方向箭头 | 保留完整 44px 命中区与准确目标，不挪材料、不改相机来腾空间 |

| 没位置的游标被直接滤掉，用户以为固定失效 | 每个未落位对象按准确 marker 身份收进原固定目录；去重计数与短提示保留 | 目录仍沿原 Popover、原列表与原定位；没有新窗口或第二套坐标真值 |

| 栏位展开、文字变化、内滚动后位置过期 | 同一 Host 观察原尺寸、文字、属性、滚动及几何 transition，释放旧 owner | 合并重测，忽略导航层自身变化；不为无限光波开永久轮询 |
| 位置 tween 造成跟相机慢半拍，换边路径穿过目标 | 移除 left/top 坐标 tween，保留图标形态、hover、press 的动效 | 实际位置跟随原相机，避免用动画制造遮挡 |
| 新鲜页面把请求读取中、读取失败都当成“没有请求” | 原诊断读取 owner 暴露 loading / ready / error；原请求区域就地重试 | 当前对话断开也能只读；原 canSend 与 prepare 准入保持 |
