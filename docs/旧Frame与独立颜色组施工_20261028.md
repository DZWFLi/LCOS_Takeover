## 本轮抓到并修的具体问题

- 原解锁值 false 被投影省略：保留原 own locked 值，原完整 echo 校验继续严格。
- 实屏 Frame 都显示“未命名框”：原名称在 Huabu 节点文件，空间几何记录没有它；GET及保存 echo 现在共用原 `space.nodes.read(id)` 只读桥，核对准确 id／类型，不回写或复制名称到第二保存者。
- 普通颜色没有定义时不能命名：只建立原颜色定义及名称，不造实体／成员；同项目同色沿原共享名称，原菜单显示“项目共享”。
- 编辑期间 Agent 先改名：保存使用开始编辑时的原名称／时间或明确无定义观察，不能悄悄换成后来值再覆盖。
- raw-only 原定位调用者漏校验：补实际原 p7 调用资格，避免跨现场的旧菜单操作新节点；复用原核对／重新读取项，不加窗口。
