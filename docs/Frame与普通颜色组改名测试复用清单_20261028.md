## 本轮最少需要补的实际用例

1. 原 CREATE_NODES 建一普通 Frame；原 GET 映射同一个 group id、label、尺寸与原 parent。原用户入口和 MCP 各做一次固定/颜色开关；只改保存的 GUI 字段，Core 不产生假 Collection/View/TargetRef，正文、几何、父链不变。
2. 原 SET_NODE_LOCKED 锁 Frame 后，用户与 Agent 修改均拒绝且 0 额外保存；解除原锁后可继续。原父子用 SET_NODE_PARENT 建好，再核本地坐标、嵌套候选与返回，不把锁或父级偷丢。
3. 普通 Frame 带损坏 reserved ref 或真实 binding 时，不得回落成可随意写的 ordinary。可沿现坏 ref 反例扩真实 Frame，不通过 raw SQL 绕过生产 owner。
4. 普通独立颜色组改名先明确真实命名 owner，再验“同色其他场景/项目”“其他色”“后来合法改名”分别保留。旧值 CAS 失败不覆盖，lost ACK 仅 GET 核对不自动再写；重开/刷新仍有名字，原输入仅 confirmed 后关闭。

## 名称空间现在是什么

- Core 原唯一约束是 metadata-repository.ts:708 的 UNIQUE(project_id,color_value)。label 不唯一，不应用“同名”当身份；实际 owner 是 definitionId + project + 同色。
- lab/native-core-color-pin-transform.mjs:18–27 在原事务内 UPDATE，WHERE 同时核 id/project/旧 updatedAt/旧 label；颜色、createdAt、membership 不改。
- lab/pilot/native-colorpin-groups.ts:25–33 当前让同色 ordinary occurrence 读取已有项目 definition label，与 typed 成员共用；这不是普通组独立名称。
- 原 native-colorpin-menu.tsx:36 要求 definitionId+updatedAt；原 page transform:109/120 对无 definition 的普通组明确禁改名并提示未接通。不能只移掉 disabled 就算完成。
- 若本轮仍选项目同色共享，沿上述真实 definition CAS，菜单“项目共享”要保留；若选普通本地独立名称，需按既定 Canvas 配置 owner 写入和回读，不能静默覆盖共享 definition 或伪造 membership 来换一个名字。本文不替主代理决定新语义。

本次只提供复用与必要反例；最终仍需新统一束中的原 Frame/颜色组入口真实 GUI 验证，不能以受控菜单或 projection 单测代替。
