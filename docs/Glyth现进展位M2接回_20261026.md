## 为什么不整挂旧 Bubble

原 [GlythThoughtBubble.tsx:35](<E:/Codex 项目/LCOS夺舍计划_20261013/lcos/huabu/apps/web/src/lcos/ui/glyth/GlythThoughtBubble.tsx:35>) 使用旧 `CanvasFloatingPopover`，依赖旧画布 attention／global-modal／定位 owner。直接叠上会带来另一套近场浮层与布局预算。

尺寸必须看完整 cascade：基础 `glyth-thought.css` 是 304px，桌面 W3 的 nearfield-density 曾覆盖到 280px；当前副本又首行导入 O1 [glyth-object-lens.css:2](<E:/Codex 项目/LCOS夺舍计划_20261013/lcos/huabu/apps/web/src/lcos/ui/glyth/glyth-object-lens.css:2>)，而原 `mountGlythThoughtView` 设置 `data-lcos-density=object`，更高优先级实际为 **228px、12.5px/19px**，下沿 field 为 43px。不能把基础 304 或 W3 README 的 280 当作今天的最终对象尺寸。

当前真实已存 Glyth 有 121×142 节点。原 [native-glyth-node-layout.css](<E:/Codex 项目/LCOS夺舍计划_20261013/lab/pilot/native-glyth-node-layout.css>) 还把自选形象进展字级压到 10px。把 228px ThoughtView 或完整 64px 光场硬塞进这条 10/12px 文字行都不合适。

本次只取原 renderer 的完整 64px 光场：对象放在现节点下沿，原 Body／label 位于其上；普通 230×44 行围绕原 44px Body，64×64 光场四侧各最多延伸 10px。装饰 `pointer-events:none`、`aria-hidden=true`，没有新卡片或点击热区。

## 真状态与通用 GUI 分开

| 输入 | 光学结果 |
| --- | --- |
| 只有 hover／focus／selected | `quiet` 静态轮廓，不制造 thinking；不要求 Run、方法或任务。 |
| 真实 `thought.source=progress` 且未过期 | 使用真实 `tone=thinking/working`。不读取原始推理或编造百分比。 |
| 仅当前任务标题 `source=task` | `quiet`，沿原 ThoughtView 规则，不冒称已有实际进展。 |
| 进展时间超过 60 秒 | `quiet`；窄 adapter 在真实时间到点更新光学过期态，不改会话、原文本或 timeline。 |
| attention／done／error | 使用原静态／收束状态，原 renderer 的 280ms 收束保留。恢复／待回答不是装饰 suppressed 的理由。 |
| 无 reference、错项目／错画布、读取中或读取失败、真实 hidden／owner 退出 | root 传 `suppressed=true`；保留原读取／错误文字，停止装饰。 |

当 `entry.status=ready` 且 projection 自身为 unavailable／recoverable／needs_user 等真实状态时，不应整体 suppress：已有 `resolveGlythThought` 会保留正确的 error／attention。打开原对话不等于改业务 phase。

## 生命周期与完整性边界

原 `mountSpectralRipple` 的 canvas、独立曲线、调色 token、增益、绘制节流、ResizeObserver、IntersectionObserver、document visibility、reduced-motion、forced-colors、停止与 destroy 均未改写。

adapter 只被动观察现节点 pointer／focus，更新自身装饰输入；不 preventDefault、stopPropagation 或捕获指针，不写选区、相机、输入、引用或 Core。卸载时释放自己的监听、IntersectionObserver、过期 timer，并调用原 destroy。

完整旧 ThoughtView 仍未恢复的内容另记：6200ms dwell、1300ms 文本替换间隔、悬停历史与详细文字、点击展开、Escape dismiss、查看过程、专门的浮层避让与回焦。不能因为本次恢复 M2 renderer 就把这些一并勾选。
