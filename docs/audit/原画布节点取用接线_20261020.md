# 原画布节点取用接线 · 2026-10-20

结论：原 TapNow 节点现在有接入成熟 Drop 的薄入口。普通左拖归原画布；右拖、Alt 左拖复用原 RightCarry，不增加目的地选择器。

## 文件与真实范围

- `lab/pilot/native-node-carry.ts`：来源快照、DOM 事件薄桥。
- `lab/pilot/native-node-carry-host.tsx`：导出 `NativeNodeCarryHost({ onNotice })`，交根任务生产挂载。

- 本子任务不改 `lcos` 参考源码、server、构建器或 `native-agent-ui.tsx`。
