## 接入 Gen2 时的三个关键坑

1. **正文读 `data.text`，别误用旧 content。** 原富文本编辑实际把 text 改成 `## **文本夺舍实测：本地编辑可保存**`，而早期 fixture 的 content 留着旧文。映射要明确唯一正文字段。
2. **撤销恢复会生成新的 TapNow node ID。** 真测删除/撤销时恢复节点与连线都换了 ID。不能直接拿 donor node ID 当 Artifact、FileRecord 或 Huabu 主键；领域身份与空间身份需单独保留、显式映射。
3. **能显示 URL 不等于能下载/取历史。** 本地上传 src 可渲染，但下载走 file_id→下载任务，查看会读生成历史。采用时要改这两条服务链，不能沿用厂商云端关联。

原添加菜单落点也会重叠，测试里需要拖开节点。Gen2 的空间经营需要提供自己的落点策略，别把原默认当成自动布局。

## 拆出来的接口和边界

| 层 | 本轮可用接口 | 正式采用的 owner |
| --- | --- | --- |
| 原 renderer/editor | 原文本与图片组件继续在原 React runtime 中执行；添加/富文本/工具栏不是自绘替代 | Gen2 前端视图层，尚未正式采用 |
| 原 Canvas store | getNodes/getEdges/getSelection/updateNode/updateNodeData/addNodes/deleteElements、视口接口；undo/redo 明确从 Canvas 父组件传入 | 这里只是 donor 隔离实验；生产 Spatial Truth 仍由 Huabu |
| 节点持久化 | 原 nodes:batchActions、connections:batchActions 被本地后端真实保存 | Gen2 采用时分别映射领域与空间写 owner |
| 文本领域内容 | 已核对 CoreArtifactClient createTextArtifact/readCanvasText/saveCanvasText；写入需 expectedRevisionId | Local Core，而非本地 JSON 或 TapNow 云端 |
| 图片领域内容 | 已跑原 Gen2 getFileRecordContent 方法的模拟路径，精确 project/artifact/revision/fileRecord 身份 | Local Core/FileRecord；不是只按时间取最新文件 |
| 几何 | 已核对 Huabu SET_NODE_GEOMETRY / CREATE_NODES / DELETE_NODES / MERGE_NODE_DATA | Huabu RFS；不是直接透传 TapNow batch wire |

`lab/node-transform.mjs` 用 AST 定位 Canvas ReactFlow children，在内存响应里加入 bridge。`lab/startup-node-bridge.js` 复用原 store 与原 React，不另造画布 store。`lab/startup-node-panel.js` 是本地接入宿主，没有自称回收的原 TSX。

这就是当前停点：下一轮可以挑一条“Gen2 文本内容 + Huabu 几何”或“Gen2 图片读取 + 原节点显示”开始真实局部接入，不用继续先反编译整包。本轮没有自动启动这个真实接入。

## 安全与验证边界

本轮仅在独立工作区改 lab/scripts/docs/evidence；旧 LCOS、复制的 lcos 源码、TapNow 安装和 reference 副本不动。没有账号、旧数据库、token、真实模型任务或收费操作；没有提交 Git/上传厂商包。

模拟数据在 `.runtime/offline-node-lab/`，二进制在其 synthetic-uploads 子目录。上传只接受 ≤2MiB PNG/JPEG/WebP 并核对字节长度/签名；不支持续传和未知动作。合成图片本身由本地 SVG 的截图产生，没有 AI 生图。

保留已有 Host/Origin、CSP、路径与体积检查。测量浏览器禁止非本实验源 HTTP、WebSocket 和 service worker。遥测仍会尝试初始化，已被 fetch/CSP/route 阻断；不把“画布可用”说成“遥测代码已全删除”。任意自定义协议/导航与普通用户浏览器的全安全边界仍不在本次证明内。

后端补了普通失败测试：跨画布引用、重复 ID、坏几何、错误批次的原子回退、不支持分享 PATCH、上传前 complete、错长度/格式/大文件。连接删除可能已被节点删除级联移除，返回明确 already_absent_connection_ids，而不是假装刚删除了对象。没有新增 hash、冻结 contract、baseline 或 gate。
