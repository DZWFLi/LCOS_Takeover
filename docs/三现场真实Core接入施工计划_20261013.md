# 三现场真实 Core 接入｜施工计划

结论：本轮只交付“原 TapNow 画布 + GN2 三现场入口外观 + 独立真实 Core/Huabu 数据”。Agent、集合、Pin、Context 面板与 Workflow 执行做对照，暂不扩施工范围。

## 目标与边界

- 原 TapNow 的切换、保存检查、文本编辑和画布渲染继续使用原实现。
- 同一测试 Project 的三个 Core Workspace 对应 Main / Context / Workflow，各有独立 canvasId。
- 内容真值在 Core；几何和空间状态在无头 Huabu。HTTP facade 只翻译协议，不建立另一份节点 JSON 真值。
- 新服务 127.0.0.1:17880，最终新数据仅 .runtime/live-surface-core-v2；首轮 .runtime/live-surface-core 原样保留供查错，不读取旧数据库、登录、密钥或真实项目文件。
- 原 LCOS、OS、TapNow 安装、reference/ 与 lcos/ 副本只读。

## 修改点

lab/server.mjs 增加独立 --surface-core 模式，旧 fixture 模式不替换；lab/node-transform.mjs 增加已安装解析器回退；scripts/start-surface-core.mjs 隔离启动；lab/startup-surface-core.js 携带页面已观察的 Core revision；scripts/surface-core-browser.mjs 实测。子代理分别维护 surface-core-facade.ts 与测试、surface-dock 三文件与测试。

## 接口与前后变化

原 --nodes：原前端 → 模拟节点 JSON，Core 未连接。

新 --surface-core：原前端 → TapNow 协议 facade → 实际 Core Repository / Huabu executor。Dock 直接调用原 Ke → PG（先 flush/preflight 再切换），不新增路由或画布 store。

只接已实现的图片读取、文本与几何保存、三现场读取/切换。未实现的生成、上传替换、复制/删除/撤销、新画布和云端功能明确失败，不回落成旧模拟成功。

## 验证、风险和回退

1. AST/语法、真实 Core 与磁盘持久化测试。
2. 浏览器验证原画布非空、图片字节、三现场选中与数据隔离、原文本编辑和几何保存、刷新。
3. 截图、页面异常、远端网络拦截和 HTTP 保护记录。

风险：厂商 bundle 更新会改变 seam；新 mode 的导入/启动失败必须关闭已启动 Core；TapNow UI 的未接功能仍可能显示入口。失败不吞掉、不假成功。关闭本次识别出的服务即可回退；旧服务和旧数据不变。

本轮不新增 hash、冻结 contract、baseline 或 gate，不提交生成任务，不安装依赖。
