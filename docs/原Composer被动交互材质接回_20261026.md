## 状态与观测标记

| 状态 | 本批行为 |
| --- | --- |
| hover | 原阻尼追随指针，光层 opacity 1。 |
| focus-within | 静态 .55 光，原输入焦点边界保留。 |
| press／touch／拖拽经过 | 原 W1 清掉指针追随；不截获事件或抢 pointer capture，原按钮／caret 操作不变。 |
| 仅 canSubmit=false／busy | 不据此禁用输入材质；这不是整个输入不可用。 |
| 真 readOnly／disabled 或 suppressed | 释放原交互，清掉 hover 和旧光点，保留原说明和控件状态。 |
| hidden／inert／aria-hidden／display:none／隐藏 class | 沿现 surface 与真实祖先进行可见性清理；恢复后从中心开始，不复活旧 hover。 |
| reduced-motion | 停指针追随、无光层 transition，允许静态 focus；不制造波纹或工作阶段。 |
| forced-colors | 去彩色装饰，保原文字、边框和按钮。 |
| ref 更换／卸载 | 释放旧宿主、监听、观察器与原 RAF，旧元素不会复活交互。 |
