### 原研究的可信度边界

旧文档把文件夹描述为青色、带「3 items」和星标，并区分 Folder 与临时 Stack；但这些是旧研究描述，不是本轮重新看见全部行为的证明。

本轮亲看了索引所列的 `v1-04.jpg`、`v5-04.jpg`：其中 Apple 图标拼贴看起来是图片卡内容，仅凭这两帧，不能证明它就是可交互的文件夹，不能把它当文件夹真实外观／展开机制的实锤。原文不覆盖改写，疑点在这里注明。

Spatial 研究主体是 Swift 原生符号与录屏，不是拿来就能挂进 React 的前端源码；目前最直接可复用、证据最清楚的文件夹视觉动效是上述 Rare UI 组件。
