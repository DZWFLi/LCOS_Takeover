## 统一接口

- `NativeTextRangeLocator`：`kind: 'selection'` + `textRange: {start, end, quote}`，UTF16 同正文索引。
- `NativeTextSingleLocator`：旧 `MaterialLocatorV1` 或新精确 Range。
- `NativeTextLocatorGroup`：`kind: 'selection'` + `locations: single[]` + 可选 `selected`；不允许嵌套，selected 必须属于列表。
- `NativeTextSourceLocator`：single 或 group。
- `normalizeNativeTextLocator`、`normalizeNativeTextLocations`：整值/整组严格校验，非法扩展不会降级成旧 label。
- `hasNativeTextLocationExtension`：检测新字段是否存在，供持久化明确拒绝坏值。
- `nativeTextLocationKey`、`nativeTextLocatorGroup`：只按真实位置去重；不自动挑第一个摘录。
- `readNativeTextSelection`、`resolveNativeTextLocation`、`attachNativeTextLocationRestore`：本 Root 生产、消费与可取消恢复。

复制、拖出、摘录的 `content.text` 与 `textRange.quote` 完全一致。生产时去掉的首尾空白会同步修正 offset，不产生“quote 已变、位置没变”的半成品。
