# TapNow 工具孤岛审计｜2026-10-13

结论：29 个 HTML 里有 24 个 MCP App 入口。多数已经是单页 bundle，JS/CSS 内联；可复用的是浏览器本地交互和 MCP Apps 桥接，不是整套 TapNow 服务。Director Markup 与 Platform Resize 已在独立 host 实测通过关键本地动作；Color Adjust 也已有像素实测。

完整逐页字节数、脚本和本地依赖闭包、桥方法、输入/输出提示、网络线索在 [evidence/tool-islands.json](../evidence/tool-islands.json)。审计可重跑：

    node scripts/tool-island-audit.mjs

## 盘点结果

- 范围是 reference/tapnow-installed/resources/web/**/*.html；共 29 个、17,976,296 字节，其中 24 个 usercontent-proxy/apps。
- 24 个 app 都把 JS 与样式放在 HTML 内，没有外部本地 JS/CSS 依赖；creative-picker 和 motion-picker 分别拆成 10、9 个内联 script，其余每页一个。
- 桌面入口 index.html 只引用本地 JS/CSS，但该入口词法依赖闭包覆盖 586 个文件、48,232,519 字节。此闭包包含 Vite 懒加载资源，是按 literal import/CSS URL/assets 路径做的静态闭包，不是 AST 精确执行图。
- app 行为归类：本地计算 2、本地编辑 9、纯展示/筛选 5、服务端动作 2、云端生成/变体 3、未知 3。未知项是 Creative Library 两个入口、Interactive Learning；Actor Emotion 已确认前端 Three.js 编辑与服务端保存，但业务 fixture 还没还原。
- app HTML 里没发现带固定 URL 的原生 HTTP/WebSocket API 调用。各 app 的服务端动作走 host SDK；MCP SDK 内的 schema/文档 URL 不算 endpoint。输入里出现 preview_url 或模型/图片资源时仍可能触发动态媒体请求；Product Kit 另含 https://files.tapnow.ai/demo/product-kit.webp 静态示例图。
- index.html 及其 bundle 含 Sentry envelope 请求；离线实测还观察到 Statsig、文件检查和缺失 BFF/归因 API，均已在首轮离线记录标明为被拦或 404。完整桌面壳因此不是本地工具岛。

## 原 proxy 的视觉主题接缝

安装包没有独立 panel-theme.css。resources/web 下的 10 个外置 CSS 是桌面页面样式；24 个 app 自己把 CSS 和产品令牌编进 HTML。mcp-app-proxy.html:184-185 明确写了 proxy 不注入样式，避免污染第三方模板；主题由宿主通过 hostContext.styles.variables 下发，View 内 SDK 再应用到 documentElement。注释提到的 packages/mcp-app-widgets/src/shared/design-tokens.css 是构建期来源指针，在本次安装 reference 和 lcos 副本里都没有该独立文件。

Platform Resize 的内置 SDK 在 platform-resize@v1.897f4688.html:203 列出 76 个 hostContext.styles.variables 白名单 key，值必须为 CSS 字符串，每项可选；styles.css 只有 fonts?: string。--panel-*、--color-background、--color-accent 等页面/令牌名不属于该 enum，不能从 hostContext.variables 任意注入。逐项完整名单在 evidence/tool-islands.json 的 themeIntegration.hostStyleSchema.allowedKeys。

因此，独立 host 载入时的白底白字记录为视觉主题集成缺口，不表示本地编辑逻辑失败，也不表示已复刻 TapNow 面板样式。此次没有改 vendor CSS；只确认了 hostContext 注入协议和它的受限变量表。

## 桥接和后端边界

根任务后续对 Platform Resize 仅通过 SDK 白名单变量传入浅色主题；握手仍成功，标题实际颜色为 rgb(29,35,41)，本地 960×540 图仍载入，文本已可读。没有注入未允许的 panel 私有变量，也没有修改厂商 CSS；不据此称完整厂商主题已还原。截图为 output/playwright/island-platform-resize-themed.png。

app 通过 window.parent.postMessage 上的 MCP Apps JSON-RPC 接入宿主。宿主回 ui/initialize 后，app 发 ui/notifications/initialized；宿主再发 ui/notifications/tool-result，数据主要在 params.structuredContent，可选 UI 状态在 params._meta["tapnow/widgetState"]。

- 状态保存方法：tapnow/setWidgetState，JSON-RPC params.state 是 app 自己的视图状态，不等于 LCOS 的项目真值。
- 业务服务方法：tools/call，入参 {name, arguments}；不同 app 的 action 名见 JSON。
- 对话入口：ui/message；如 islands host 不接模型，可明确拒绝，前端编辑和本地预览仍可独立测。
- Color Adjust 当前 host 对未知工具动作以 -32601 明确拒绝，逻辑在 lab/host.html:137-145；初始化和状态处理在 :179-201。新 islands host 可沿用“明确未接入”的边界。

显式服务端/云端动作：

- animatic_variants_lookup / animatic_variants_submit
- ecommerce_photoset_generate 与 tapnow/estimateGenerationCost
- previs_variants_lookup / previs_variants_submit，另有 app-reply run status/validation

这些页面没有展示模型供应商或直接 API；能确定的是宿主必须承接 action，底层是否调用模型需另看 server tool 实现。

## 暂缓项与证据位置

- Layer Composer 前端有完整 Canvas 图层、排序和变换预览，但 Apply 走 layer_composer_apply。structuredContent 必须带 source_sha256、尺寸、WebP data URI 等字段；先不拿它当首批 fixture。入口 validator 与 Apply 都在 layer-composer@v1.067126cf.html:355。
- E-commerce Photo Set、Animatic v2、Previs v3 明确走生成/变体 server tools，复用表单/结果 UI 可行，生成不可本地化。
- Ad Review 与 Cutlist Review 的标记、备注、保留区间在本地编辑，但依赖宿主注入的图片/视频资源；Cutlist UI 不导出视频。
- scripts/tool-island-audit.mjs 只读 reference 副本，用 Node 内置模块生成逐页证据。报告不把 SDK 文档 URL 计成 endpoint；JSON 中闭包扫描方法和静态判断范围都有注明。
