# 新接功能 GUI 跟审与极简接回

日期：2026-10-27。以下是本批已施工和实际验证的结果；整体 GN2 持续目标仍未结项。

## 结论与取用原则

本批已把阅读设置从两处收敛到同一个原 More、底部反馈从三槽合到一槽，修复子现场 Color Pin 和 Agent 强调的即时显示。新增 GUI 窗口0、常驻入口0。旧功能和错误提示保留。

新增能力必须同步审计入口、窗口、反馈密度、回程和 Agent 操作。游标、固定、颜色标记、强调和光效是通用视觉整理表达，可以保存和随时修改；不附带阶段确认、Run 或版本采纳流程。Context、Workflow 的领域操作沿 TapNow 原页面和原展开方式接入。该原则不等于所有 Agent 标记工具已经完成，缺口见后文。

## 后续优先级与未实证边界

| 优先级 | 未接项 | 处理方向 |
| --- | --- | --- |
| P1 | 导航固定、Color Pin的Agent编辑仍缺当前会话工具接入；普通无canonical载体固定、部分typed混合成员authoring仍未齐 | 复用各自现有标记owner及原入口；不能用强调bool冒充固定或颜色标记 |
| P1 | child已保存但来源关联失败的用户核对/补接UI | 保已存身份及原错误/防重复创建，补同一child的原流程恢复；当前仅后端受控失败/补接验证，未称整页异常路径完成 |
| P1 | 冷启动原资产变换 | 实际首轮ready约53–55秒；沿同一变换链准备构建资产，不能跳过loader掩盖 |
| P2 | 未起拖的pointercancel边界 | 先实证，再沿原handler补；HTML native drag本身会发pointercancel，不能盲清缓存卸载按钮 |
| 持续 | 全量Arc/W3/Figma和其他历史GUI余项 | 延续原逐功能账；本批完成不代表整体GN2已无可改 |

- 原选区 handler 在 pointerdown 后缓存摘录，尚未实证 pointercancel／无 dragstart 的遗留浮条场景。HTML 原生拖动开始本身会产生 pointercancel，不能简单清空并卸载按钮，反而打断真实拖动。先保留原功能并记账。
- 已发现 Undo 进行中并发 GET Canvas 的瞬时409。原读取器对绑定变化的保护可受控复现，但真实那次未采响应正文，不能唯一归因。验证改为先等原 Undo/Redo HTTP 最终回执，再读结果；不吞409、不重试创建，也不放宽读取保护。
- 实际MCP只读发现5个工具、调用数0；旧真实会话transport仍断开，Host现会话挂载不可用，未冒称续聊连接或发送恢复。本批没有发送模型消息。
