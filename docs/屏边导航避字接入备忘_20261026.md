## 接口与接法

| 接口 | 返回与用途 |
|---|---|
| `readNativeNavigationObstacles(document,{safeRect,pane?})` | 返回 `{rects,elements,unmeasured}`。沿当前原 Canvas 提取文字行、标题和实际控件；其他页面、资料库或 Popover 正文不当作画布材料。保留卡片空白，按原祖先 overflow、边框、滚动条和 CSS 缩放裁切。 |
| `layoutNativeNavigationMarkers({targets,safeRect,obstacles})` | `targets` 为 `{id,targetRect,previousPhase?}[]`；返回 `{markers,unplaced,blockedIds,forbiddenRects}`。调用现有原投影，不创建坐标真值或写入 Canvas。 |
| `unplaced` | 逐项保留 `{id,reason}`，区分 `blocked`、`insufficient-space`、`geometry-unavailable`；不能再用 `flatMap` 默默丢掉目标。 |

`safeRect` 继续使用 [visibleCanvas](<E:/Codex 项目/LCOS夺舍计划_20261013/lab/pilot/native-material-placement-client.ts:47>) 对原左右栏及底部面板的实测结果。不要新增固定栏宽，也不要移动相机或材料来给游标腾位置。材料位置仍由原 API 提供；保留 44px 热区、单目标单游标、真实方向及原聚合成员身份。

## 必须一起接入的重测

现 [Host 监听](<E:/Codex 项目/LCOS夺舍计划_20261013/lab/pilot/native-navigation-ui.tsx:23>) 只观察 pane 尺寸和子节点增删，不能覆盖所有实际布局变化。接入时沿同一个 owner 完成：

- 使用返回的 `elements` 扩充现有 `ResizeObserver`，覆盖原文字宿主、工具栏和裁切祖先；元素增删时更新观察集合并释放旧观察。
- 对这些原 owner 的 `style`、`class`、`hidden`、`aria-hidden`、`data-state` 等可见性/位置变化重测。原 Dock 只改位置时，单靠尺寸观察不够。
- 监听原正文/面板内部滚动，可沿现 document 捕获 `scroll`；原相机、窗口尺寸及可见性变化也须重测。继续用一次 rAF 合并，忽略游标/光环自身变化，避免互相追逐。

## 无槽和测量失败

同边无槽或剩余尺寸不足时，把 `unplaced` 的准确目标交给**既有固定目录入口与原 Popover**，明确计数/提示并保持可进入；不删除固定记录，不缩小热区，不冒充已定位，不另开窗口。当前模块只提供该数据，目录承接尚未接入。

`unmeasured` 表示已识别的内容测量失败，不能把它解释为材料空白或“已完整避让”。不得退回整张 node 大矩形来掩盖失败。真实页面验收仍需补：窄屏 H1 与正文、左右栏开关、正文滚动、浮条/小地图/Popover、无槽目录可达及迟到布局变化；保留实际矩形、顶层命中和截图证据。
