# 原生文本双视图与动态呈现

## 本轮目标与短计划

目标：保留 TapNow 原文本节点／正文显示／菜单／相机／历史，优先使用原正文编辑器，只在缺少的导图与结构编辑处嵌 Gen1 成熟叶子；接 GEN2 原密度算法与文字呈现，沿 Core 保存同一份 Markdown，交付独立可查看预览。

- Files：仅 `lab/` 原生文本薄接缝、现有 launcher／server／facade 的独立文本模式、必要的定向测试与本文。`reference/`、`lcos/`、原 GN2 只读。
- Before → After：旧文本入口整体挂 GN2 body，新文本入口优先保持原 TapNow 阅读／正文编辑；导图叶子与 GEN2 呈现只补差异。新模式不改旧服务运行产物。
- Interface：不新增 Core 领域类型、数据库或执行语义；同一 Canvas／Artifact／View／Revision，原 O8 历史与保存回执继续负责写入。仅在合成 runtime 写入。
- Tests：先静态接缝／纯函数，再真实 GUI 覆盖双视图、编辑／取消、密度缩放／尺寸变化、一次保存／Undo／Redo与刷新；旧 17881／53861／56111 不做 GUI 写入、不重启、不重新构建。
- Risk：原媒体编辑器保存的字段／Markdown 转换需实际测量；不能以换两个按钮冒称完整 Gen1 编辑功能。编辑稳定性、格式往返、未知保存回执与原历史不得退化。
- Rollback：撤掉独立文本模式与本轮薄接缝即可，保留新合成 runtime 和证据；不迁移旧数据。

本轮不做 Assembly、Rail、Drop 或真实 Provider 执行。默认不新增 hash 清单、冻结 contract、baseline 或 gate，不删除已有安全措施。

## 验证环境

Browser plugin not available；使用项目已安装的 Playwright Core 与 Chrome，不下载依赖。浏览器只允许本轮 loopback，真实画布操作和保存仅在新的 `isolated-*` 合成 runtime。截图放既有外部 visualizations 工作区。

文本原生优先版已实现；最终独立 runtime 的 GUI 复跑结果见下文。不是 Gen1 文本全功能、完整 GEN2 字号生命周期或整个夺舍产品完成。

## 数据和现场归属

- 正文与导图共用同一 Canvas occurrence、Artifact、View、Revision 和 Markdown。摘要／标题级呈现只作用于阅读投影，不写回截短正文。
- 模式＋尺寸＋居中位置经原单次 update 提交；切回正文恢复切图前原尺寸。原相机负责选中对象定位。
- 草稿必须精确匹配 project／canvas／node／Artifact／View／revision。相同 Artifact 和 revision 出现在另一现场，也不能把旧草稿提交过去。
- read 错误、notice、pending 和编辑器均按当前 key／API 隔离；回执核对完整身份，允许自己的保存推进 revision。未确认操作只核对，不自动重放写入；返回原现场可从现有 save-port registry 恢复待确认状态。
- Gen1 导图根标题改名本轮明确拒绝，并保留草稿；请走原节点命名入口。未把 unsupported 伪装成成功。

## 真实失败与修复，不藏红灯

1. 不完整 ref 的 `undefined === undefined` 误命中 primary：补非空完整字段判定。
2. 跨现场旧草稿／保存状态：补精确 occurrence 判定、pending 归属和回执身份；避免旧保存回调污染新现场或留下永久 busy。纯函数负例和原 port 的迟到场景测试通过；尚未做本版 UI 跨现场保存竞态完整 GUI。
3. 初次模式切换的 Undo：初始 DTO 缺省 `lcosTextViewMode`，原 O8 撤销恢复缺省后，后端 MERGE 会留住 `mindmap`。仅新 `nativeTextPilot` 读模型显式投影默认 `text`，让原历史带回完整语义；旧模式默认 false、不变。
4. fresh 合成图片 360×240 低于原图节点的 250px 最小高度，冷启动原组件会改成 375×250。测试单独记录这一笔原自动尺寸纠正，再以纠正后的画布作为文本测试起点；不是用户拖图，也不称整轮新项目非目标零变化。
5. 原 ResizeObserver 还可能发出完全不变的 image measured echo。测试仅允许同一合成图片、相同数据／引用／位置／尺寸、当前正文 CAS 的精确无变化回声，单独计数；不消耗文本动作额度，不放行任意非目标更新。
6. 测试脚本自身修过原编辑器光标定位、响应 body 解析竞态、旧 `content` 镜像、原 `parent_id:''` 回声、导图标签省略及 Agent 蒙层退场等待。正文／Core／文件精确断言没有取消。所有失败 JSON／截图仍在外部 visualizations 目录。
7. 实际截图发现 Gen1 导图建议高度 182px 低于原壳 250px，导致背景／resizer 超出选框。保留原壳下限，在叶子尺寸建议处适配至至少 250×250；最终 GUI 额外比对原 shell 与 body 的屏幕矩形一致，不靠 CSS 藏溢出。

原 Tiptap 是自动保存：未改字打开再返回才是零写入，不能把它叫取消草稿。Gen1 导图有显式取消，另行验证。缩放必须真 Control+wheel；未用 API zoomTo 冒充鼠标测量。

## 尚未接齐的边界

- 已接 GEN2 信息密度与迟滞；**尚未迁入 `useTextAutoSize` 拖框自适应→锁字号→编辑重排的完整生命周期**。本版原生改宽是原字号换行，不宣称已完成动态字号锁定。
- 本版 GUI 覆盖正文和普通导图分支；Gen1 提升层级、整支剪切／复制粘贴等此前在另一隔离版本有证据，不能挪作本版全套结构动作验收。
- 额外 View 正文写入、导图根标题、分支拖出创建及创建 Undo/Redo没有在本版补齐。Drop 仍留独立轮次。
- 不含游标／Rail 新接入、Assembly 融合、三现场完整经营、Agent 真执行或真实 Provider。界面中的其他旧入口不代表本轮已验收。
- 原离线 `/api/bff/platform/config` 与 `/api/v1/canvas/plugins/...` 仍返回 501；启动 execution reconcile、Agent suggestions 和 telemetry 在文本测试中被主动拦截并记录。不能称整机零接口／console 错误。
