- Goal：把已有 Milkdown 正文、TextFaces 结构视图和 GN2 密度接到原 TapNow 文本 child，实际验证编辑、保存、原历史及刷新。完整接入目标不缩减。

- Before / After：现有文本候选仅 bundle，save factory 已安装但无 caller；本批让成熟 body 成为原 renderer 的真实 child，保存经过原 updateNodeData/batch/history，Core 保持唯一正文 owner。
- Contract：不新增业务 contract。复用已有 CanvasTextSnapshot/Write、ProjectionBinding、原 node API 与既有 native-save receipt。未知回执只读核对，不直接 Core PUT 后再 echo，不重发 writer。
- Tests：source transform 幂等/drift、原件只读、真实 bundle、窄字段/原 API 测试、隔离 Core 回归；真实 Chrome 的正文/结构编辑、保存/撤销/重做/重开及精确 Core Revision/FileRecord 读回。
- Risk：只允许合成项目与明确测试材料；保留只读/锁定、身份、CAS、路径保护；不引入第二 Canvas/历史或静默 gesture no-op。额外 View 的未映射保存仍明确拒绝。
- Rollback：撤掉实验 AST/source-transform 注册并 rebuild；保留独立 runtime 数据与证据，不回滚用户正文、不改 copied donor。

上一轮以产品架构确认和只读核查为主，没有新增运行能力。本轮从实际代码 caller 和浏览器动作推进，不以更多说明替代接入。
