## 实屏发现并修复的缺陷

窄屏点击附注后，原 Viewer 会短暂出现，然后 Viewer 和方法 Gallery 一起消失。真实事件轨迹确认：附注 Host 的 effect 先释放阅读 lease，才连带关闭方法来源，并非返回按钮被裁掉。

原因是原 Canvas 重渲染会传入新的 `NativeViewerParts` 包装对象。材料 Viewer 已通过 `latestParts` 引用处理这一点，附注 Viewer 却把整个包装对象作为 effect 依赖。现按原材料 owner 的做法保存最新部件引用，保留真实 runtime、项目、Canvas、API 变化时的清理；普通包装对象更新不再取消当前阅读。
