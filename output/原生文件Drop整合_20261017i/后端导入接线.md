## 原 UniversalResource／Capture 的真实语义

- 当前 `UniversalResourceImportService.importFile/afterImport` 保留同一 Artifact／Revision／View，再生成派生 resource descriptor；不是 Resource-only 替身，不另造 canonical 成员。
- 原 `POST /projects/:projectId/resources/import-url` 是 URL 的正确 producer。它生成真实 link Markdown 原件及 resource descriptor；后续 LinkAnalyzer 可尝试远端元数据抓取，失败为 partial。与本地离线边界有关，**本次仅源码核查，没有调用远端 URL／没有宣称 URL Drop 已接通**。single-PUT 拒 `.url`／`.webloc`，也不把文本 URL 当图片。
- 原 `resources/import-archive` 是“按包导入／展开”的另一种明确意图，有原 package 文件数／尺寸／路径／敏感文件保护；本次 `.zip` 上传是保留原 ZIP 文件的普通 Import Copy，不冒充该 package producer。
- 当前选用的 CaptureSpaceService `#importItem:308`：URL 调上述 importUrl；文字 blob 调原 createTextArtifact；非文字 blob 当前固定命名 PNG；本地路径调用 resources.importFile 保留文件名。**因此不能把所有新文件绕进 Capture blob 分支**。此次 single-PUT 直接复用通用原 imports，未改 Capture。
