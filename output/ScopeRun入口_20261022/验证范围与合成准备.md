## 页面验证

scripts/native-scope-run-browser.mjs 只使用原页面动作：

1. Scope Run → 原右栏任务详情 → 原 Header 返回库内预览。
2. Scope 轻量 Run GET 503 → 原成员仍显示 → 原重新读取。
3. 外层集合 → 内层集合，轻量 Run GET 503 的相同原位恢复。
4. 内层 Run → 同一原任务详情 → 返回原集合成员。
5. 任务 review GET 503 → 原任务页重试读取 → 同一 Run → 返回。
6. 真 manifest 输入材料 → 原 Viewer → Escape 回任务 → 返回集合。
7. 普通任务列表 → 详情 → 列表 → 对话回归。
8. 比较 Core、三画布、集合、presentation、Run、输入、光标、引用、相机和 Stage 地址；不接受意外领域写入。

固定窄窗 1040×760。浏览器为现有 Playwright Core／Chrome，所有远端 HTTP 和 WebSocket 被拦截。附加在实际产品包尾部的观察函数只有 getState 读取，没有隐藏 setter 或模拟导航事件。

本轮不测 dispatch、cancel、retry、accept、reject 或 provider 执行。后续 Run 的真实创建／执行不会为了检查返回栈而触发，返回栈由既有独立路由测试覆盖。
