## 真正发现并修掉的问题

由产品所有者完成修复，本脚本重跑证实：

- 窄窗原库 Popover 盖住任务 Header 返回键：任务／对话阅读期间暂停原 Popover 显示，返回与取消时清理，保持同一已挂载路径。
- Run 轻量读取失败仅有“请重新读取”文案却缺动作：接回原 actions 中的重新读取按钮。
- 任务内材料 Viewer 的 Escape 被原库 Radix 标记吞掉：当前受控 Viewer 接手自己的关闭，不继承库返回来源、不跳过任务。
- 点击前 Run 读取失败被统一误报“内容已变化”：先报告具体读取原因。
- 返回清理从 React functional updater 移出，最终实屏未出现跨组件更新警告。
- 主动收起／换对话原先仅解除 hidden、却留下 TS 覆盖新对话：取消现在调用原 onClose 收起旧预览；Header 返回仍恢复同一 TS。
