# R2 源码迁移地图：如何从样机进入 LCOS Gen2

本文件是**接入说明**，不是新 Contract、数据库或门禁。禁止根据本文件自创 Goal Truth / Progress Store。

## 1. 取什么，不取什么

| 在 R2 HTML 中 | 对应位置 | 生产采用 |
|---|---|---|
| 目标轴本体 | `.goal-object`, `.goal-header`, `.goal-rail` | 提炼为 Huabu 节点的轻量 body；由既有 NodeWrapper 负责位置、选择和尺寸 |
| 阶段珠点 / 图标 | `.stage`, `.bead`, `.stage-icon` | 保留 39px 命中区域、41px 阶段节奏；来自真实阶段数组 |
| 状态视觉 | `data-status`, `statusName`, `statusIcon` | UI 只做表现映射；不能把 Run 的单次成功当作整个 Stage 完成 |
| 近场详情 | `.goal-lens`, `.lens-head`, `.lens-essentials`, `.lens-assets` | 保持 222px 小透镜、仅 1–2 行身份信息；接既有浮层 / safeRect owner |
| 来源 / 结果的差异 | `.folder-glyph`, `.paper-glyph`, `.asset-chip`, `.lens-tray` | 来源绑定真实 Source ref；结果绑定 Result/Artifact ref；详细预览交给现有 Reader / Work View |
| 启闭与边缘翻转 | `showAt`, `switchTray`, `positionLens`, `hideLens` | 迁行为；视口定位与被占区域避让交给现有 Huabu/LCOS 机制 |
| 缩放显隐 | `applyView`, `.world[data-lod]` | 只保留密度行为；正式改用现有画布的 Camera / useLcosDensity |

### 绝对不要搬进生产的演示机械

- `#board`, `.world`, `view={scale,tx,ty}`、`applyView()` 的模拟相机。
- `#dragGoal`, `drag`, `board.addEventListener('pointerdown'/'pointermove'/'wheel')` 的独立画布手势。
- `#casePicker`, `settings`, `mode`, `S[]` 里的样例数据，以及右下角 Lab 操作区。
- `#toast` 上“示例数据，生产版由 Focus 定位原件”的本地提示不能冒充真正 Focus 成功。
- 临时 Hover / Pin 状态不要建成第二套 Project / Goal / Stage 数据库；它们是纯 UI 的短生命周期行为。

## 2. HTML 文件中可直接定位的确切名称

**DOM 锚点**：`#goal`, `#goalFraction`, `#goalRail`, `#threadDone`, `#threadLive`, `#lens`, `#lensTitle`, `#lensState`, `#lensEssentials`, `#lensAssets`, `#lensTray`。

**JS 数据**：`S[]` 为 5 个模拟阶段（含名称、阶段职能 type、执行者 owner、工具 tool、skill、sources、results）；`settings` 为 working/waiting/failed/complete/unknown 五种**演示状态预设**；`statusName` / `statusIcon` 做视觉派生。

**JS 重点函数**：`renderStages()`、`renderEssentials()`、`renderAssetButtons()`、`renderTray()`、`showAt()`、`switchTray()`、`positionLens()`、`hideLens()`；其它 `setMode()`、`applyView()`、画布的鼠标监听为独立演示壳。

**设计变量**（CSS `:root` / `[data-theme="dark"]`）：`--done`, `--current`, `--waiting`, `--failed`, `--future`, `--source`, `--result`、背景与边框 token；接生产时应映射到现有 Gen2 变量而非强行新增独立色彩系统。

## 4. 安全与真实性边界

- **不新增新 hash、额外 baseline 或 gate**。项目原有安全/权限/提交保护不应删除。
- 用户只批准了设计形态展示，**未批准将独立模拟的 Core/Window/Canvas owner 写进主线**。
- `实际发生` / `尚未记录` / `计划使用` 要分清；Tool / Skill 只有权威调用/引用记录才标为已用。
- 收起、固定、窗口翻边等视觉行为可在没有后端连接时实现；**完成、失败和结果成立必须来自真实记录**。
- 当 Hover 进入小透镜时应能继续移动到材料按钮，不要出现空隙闪烁；键盘 Tab、Enter、上下键、Esc 有等价路径；Reduced Motion 不影响可理解性。

## 5. 单功能验证顺序

1. 先用 HTML 预览核对默认、第三珠 Hover、Pin、材料展开、等待/失败、远距 LOD、深色/窄屏。
2. 正式 Gen2 接入后在**同一真实画布**测试 Hover → 固定 → 点击来源 → 真实 Focus 原件 → Return 同一阶段 → Esc 收起。
3. 只记录真实差异和回归，不因独立 HTML 可以拖动就宣布 Gen2 的 Camera/Drop 整体通过。
