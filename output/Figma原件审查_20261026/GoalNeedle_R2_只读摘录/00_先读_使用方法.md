# LCOS Gen2｜Goal Needle R2 跨会话交接包

> 2026-10-10。已完成的是**离线交互设计样机**，非 Gen2 生产集成，非真实项目数据。  
> 这份包用于让另一个 ChatGPT / Codex 会话从**具体可运行结果和已裁决的设计**继续，不要再从头猜方案。

## 一分钟接管

1. **先双击** `01_设计与可运行样机/GoalNeedle_R2_直接双击打开.html`，在桌面浏览器中直接使用，无需 npm、服务器、API Key、CDN 或外部图片。
2. 体验：默认一行标题 + 5 个状态珠点 → Hover 第 3 阶段 → 点击固定 → 点击文件夹或叠纸展开 → Esc 收起 → 切换右下角的等待/失败/完成/无证据 → 滚轮看 LOD / 拖动看位置 → 切深色。
3. 阅读 `01_设计与可运行样机/R2_设计规范_完整归档.md`，再读 `02_接入交接/源码迁移地图.md`。
4. 如果下一会话负责设计细化，直接基于 HTML 修改 CSS/互动并复测；如果负责 Gen2 集成，按 `02_接入交接/接手续工提示词.md` 先核 GitHub **当前实际分支**，再只抽取视觉组件，不搬入演示的画布状态机。

## 核心视觉裁决

- 组件是放在 **Workflow 世界坐标**里的单个目标过程物件，**不是桌面 Pet，也不是独立页面 / SaaS 卡片**。
- **常驻仅一行目标名称与 `02 / 05`**；阶段由颜色 + 图形 + 小图标表达，不常驻五行阶段名。
- hover 的小透镜宽约 **222px**、标准高约 **133px**，紧贴当前珠点。执行者 / 工具 / Skill 占一行；来源（文件夹）与结果（叠纸）占一行。点击数量才局部展开 2–3 项，不铺大面板。
- 完成 / 工作 / 等待 / 失败 / 未开始 / 无证据区别明确，**不自动推进，不猜百分比**。
- 画布 Camera、Selection、Drop、Focus、Reader、Window 由 Gen2/Huabu 现有实现拥有；原 HTML 的平移、缩放、拖动只为独立展示。
