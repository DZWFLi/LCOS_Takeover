## 与客户端约定

```text
POST /api/lcos/canvases/:canvasId/collections:project
{ collectionId, position?: {x,y} }

GET /api/lcos/canvases/:canvasId/collections/:collectionId/projection
```

position 是本次明确落点的按值副本。初次有则原样传入 projector；重复放置不移动已有 carrier。原请求尺寸 hint 248×244，实际尺寸以原 RFS 创建/原 renderer 测量回执为准。

回包有真实 `project_id/canvas_id/workspace_id/collection_id`、`collection`、`presentation_received`、原 `presentation`、原 `binding`、原生 `node`，并固定 `provider_execution_started:false`。首次投影额外返回原 `assembly_receipt`；只有实际新增成员时才有该原操作的 `change_set_id`。同一 Collection 先 Main 后 Context 时，两者共用原 root Presentation，第二处是原 `already-member`，没有假造新 ChangeSet。GET 不合成 Assembly 成功行。

| GET 状态 | 含义与动作 |
| --- | --- |
| absent，未 received、无 binding | 正常首次状态；新明确放置意图可单次 POST。 |
| absent，已 received、无 binding 且无精确 carrier echo | 已被原 Assembly 接收但尚未有本 Canvas 载体，可首次投影；兼容原旧 caller，也支持同 Collection Main→Context。仍经原 already-member 回执，不重写成员。 |
| partial，无 binding 但已有精确 carrier echo | 原 CREATE 已发生，绑定未完整确认；仅 GET 核对，不重放 projector。 |
| partial，binding 缺原 carrier 或缺 Presentation 成员 | 保留真实事实；不自动 stale-binding repair/补成员/另造节点。 |
| present | 原 Presentation 成员、同 Canvas binding、同 NodeID、native pile/ref 均读回吻合；重复 POST 幂等、不再写 Assembly、不挪原位置。 |

客户端由 native_library_flow 独占接入：正常放置先原保存 owner flush → GET 准入 → 单次 POST → 原 O8 carrier 回填；unknown 后 fresh signal 只 GET，不 flush、不因 absent 自动重放。预览关开后的 UI 记忆仍缺，见前端分项，不能把后端防重写成此限制已修。
